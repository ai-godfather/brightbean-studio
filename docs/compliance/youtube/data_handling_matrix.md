# YouTube and Google data handling matrix

| Data or action | Source / scope | Product purpose | Stored | Refresh / retention | Shared | Deletion |
|---|---|---|---|---|---|---|
| OAuth access and refresh tokens | Google OAuth; all authorized scopes | Authenticate requests approved by the user | Encrypted database fields | Kept only while the connection is active; authorization normally checked every 6 hours | Google endpoints only, plus infrastructure processors needed to run the service | In-product disconnect revokes the grant and removes the account immediately; invalid authorization is purged within 30 days |
| Channel ID, name, handle, avatar | YouTube Data API; `youtube.readonly` | Identify the selected channel in the workspace | Connected-account record | Refreshed during health checks, normally every 6 hours and at least every 30 days | Authorized workspace users; infrastructure processors | Cascade-deleted with the connected account |
| Subscriber, view and video counts | YouTube Data API; `youtube.readonly` | Current channel statistics | Current account value and/or dated analytics snapshots | Current profile value refreshed during health checks; historical statistics retained only while authorization is valid and needed | Channel owner or authorized workspace members | Cascade-deleted with the connected account |
| User-selected upload media | User upload plus `youtube.upload` | Publish the selected video/Short | BrightBean media library according to workspace retention | User-controlled workspace content; not YouTube API data until transmitted | YouTube for the requested upload; configured storage/video processors as disclosed | User deletes media/workspace, or requests account deletion |
| Title, description, tags, category, made-for-kids and visibility | User input; `youtube.upload` | Configure the requested upload | Publishing record | Kept as user-authored publishing history | YouTube for the requested upload; authorized workspace users | Deleted with the publishing record/workspace |
| YouTube video ID and publishing state | YouTube upload response | Link the local publishing result to the YouTube resource | `PlatformPost.platform_post_id` and status fields | Kept as publishing history while the connection/workspace exists | Authorized workspace users | Deleted with the connected account or workspace |
| Raw upload API response | YouTube Data API | Not required after upload | Not retained after this compliance change | Existing rows are scrubbed by migration | Not shared | Removed by migration; new responses are discarded |
| Comment IDs, authors, text, threads and replies | YouTube Data API; `youtube.force-ssl` | User-requested inbox, first-comment and reply features | Inbox/publishing records as needed for the feature | Refreshed through product sync; deleted with account/workspace | Authorized workspace users; YouTube for write actions | Deleted with the connected account or applicable data-deletion request |
| Views, watch time, average view percentage, subscriber changes, likes, comments and shares | YouTube Data/Analytics APIs; read and analytics scopes | Channel-owner analytics | Dated snapshots | Recent videos refreshed hourly-to-weekly based on age; background post sync stops after 90 days; historical authorized statistics may remain while authorization is reconfirmed at least every 30 days | Channel owner or authorized workspace members | Cascade-deleted with the connected account; invalid authorization purged within 30 days |
| Logs and security events | BrightBean infrastructure | Security, abuse prevention and troubleshooting | Restricted operational logs | Limited logs/backups rotate within up to 90 days as disclosed | Authorized operators and infrastructure processors | Rotation or legal/security exception described in Privacy Policy |

BrightBean does not store Google passwords, YouTube viewing history, private subscriptions, financial/monetization data, or independently derived YouTube scores. It does not sell Google user data or use it for advertising or generalized AI-model training.
